# webnKraft - Website V3 — webnKraft rebrand

This is the customer-facing prototype with integrated AI Video & Visual Content offering for a web design/development business.

## Files

- index.html - page structure, content, SEO metadata and structured data
- styles.css - responsive visual design
- script.js - navigation and interactive Project Builder
- robots.txt - crawler access
- sitemap.xml - initial XML sitemap

## Before publishing

1. The selected brand domain is `https://webnkraft.com/`. Confirm the domain is registered and points to the deployed site before launch.
2. The website brand is standardized as `webnKraft`.
3. Replace the placeholder logo and social image paths with real assets.
4. Connect the Project Builder form to a backend/database/email service.
5. Add real portfolio projects and genuine business contact details.
6. Add Privacy Policy, Terms, and any required legal pages.
7. Submit the sitemap in Google Search Console after the domain is live.

## Important

The Project Builder currently stores nothing on a server. It validates the form and logs the prepared payload in the browser console. Do not treat this as production lead storage yet.

The showcase currently uses CSS concept visuals rather than real video files. Replace these cards with optimized real video assets when your friend's portfolio is ready. Do not upload very large source files directly to the website.


## V3 Smart Project Builder
The builder now has six steps: project type, business context, functionality, visual content, budget/launch, and contact/project summary. It provides contextual planning tips and video recommendations. It still does not save leads to a server; the next phase will add a backend/database and admin dashboard.
